# Real-Time-Voice-Agent
Real-time Voice &amp; Conversational AI using Python, Pipecat/LiveKit, and streaming ASR/LLM/TTS. Build a production-grade voice agent with turn detection, barge-in, streaming TTS, &lt;800ms latency, emotion-aware speech, noise/multi-speaker handling, and full-duplex communication. Core focus: AI/LLM, real-time systems &amp; audio processing.
